# Report format

Read this file in Step 6 to lay out the report. Reply in the user's language, but keep file names, folder paths and the Skill name unchanged.

## 1. Headline

One line: `Claim Readiness: N assets checked. H High, M Medium, C Critical. Average score S%.`

If any step failed, put `Partial audit` before the headline and name the checks that were not run.

## 2. Dashboard

A table of all assets, sorted by score from lowest to highest.

| Asset | Value | Score | Band | Receipt | Dated photo | Serial | Coverage | Change |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Café espresso machine | 3,100 | 25% | Critical | missing | missing | missing | covered | new |

Use `ok`, `partial`, `missing` or `not checked` in the check columns. Fill Change only when Step 2 returned a previous report: show `+50` or `-10`, or `new` for an asset that was not in it.

## 3. Critical assets

For each Critical asset, the diagnosis line, then the files found for it (paths), so the user can see what the score is based on.

## 4. Evidence Gap Action List

A numbered list ranked as the rubric describes. Each item: the action, the destination folder, and the effect on the score.

`1. Photograph the serial number plate of the Café espresso machine and save it to Assets/Appliances. +50 points: 25% → 75%.`

Keep the list to 10 actions, and say how many more there are.

## 5. Scope and limits

- The folders scanned, and how many documents and photos were checked.
- Any caps that were reached (500 files, 300 photos).
- Files that could not be read.
- Assets marked "possible match".
- This sentence: `This score measures how complete your evidence is. It is not insurance advice and does not predict whether an insurer will pay.`

End by offering to save the report (Step 7).
